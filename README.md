# ZCodeDeck

> 版本 v0.5.3(2026-09-04) · Codex Micro 的软件版:一个悬浮在桌面边缘的小窗,盯着 ZCode 干活,替你按"批准",顺手报账。需求全量清单见 `docs/ZCodeDeck_需求文档_v4.0.md`。

## 收起与展开

点窗口右上角的 **›** 收起:窗口滑向右缘淡出,变成一枚 30px 状态圆钉贴在屏幕右缘,颜色实时跟随会话状态(思考蓝/执行绿/待批琥珀/出错红)。收起期间来了审批卡,**圆钉琥珀脉冲提醒**但不自动展开,你单击圆钉时才展开(滑出+淡入);圆钉可沿边缘上下拖动;收起状态重启后保持。会话完成后"已完成"保持加粗显示(未读态),直到该会话有新动作。

## 它做什么

| Codex Micro 硬件 | ZCodeDeck |
|---|---|
| 按键底灯(思考闪灯/跑码变色/搞定亮灯/出错红灯) | 窗框状态色 + 托盘图标:思考呼吸蓝、执行绿、待批准琥珀闪烁、出错红 |
| 接受键 | 审批卡片上的"批准 / 接受计划"按钮,直接远程放行 |
| 拒绝键 | "拒绝"按钮 |
| 重新思考键 | "续跑"按钮(托盘开启续跑键后,任务停止时 8 秒内可一键继续) |
| 无 | 官方剩余额度百分比 + 今日/5小时窗/7天 token 消耗 + 多会话计数 + 只读自动放行开关 |

## 快速开始

1. 双击 `启动悬浮窗.bat`(首次自动装 PySide6);窗口出现在屏幕右侧,可拖动,位置自动记忆,托盘常驻。
2. 首次启动会自动把 hook 写进 `~/.zcode/cli/config.json`(原配置自动备份;已装旧版会自动升级)。
3. **新开**一个 ZCode 会话(已在运行的会话不加载 hook),之后:
   - 它思考、跑工具、出错,窗框颜色实时变;
   - 弹权限确认时,悬浮窗出现审批卡,点"批准"会话继续走,点"拒绝"则退回;
   - 悬浮窗没开或没点,超时后回退终端里的正常提示,不影响干活。
4. 托盘右键三个开关:**续跑键**(默认关,开启后每次收尾最多等 8 秒)、**只读自动放行**(默认关,Read/Grep/Glob/LS/TodoRead/WebSearch 免确认)、**开机自启**。

## 官方剩余额度(可选)

面板默认显示本地记账。想看智谱官方的"5 小时窗口剩余百分比",把 bigmodel 的 API key 填进 `~/.zcode/deck/config.json`:

```json
{ "bigmodel_api_key": "你的key" }
```

存盘后悬浮窗 5 分钟内自动显示。查的是官方用量端点,与官方 glm-plan-usage 插件同源;桌面版登录 token 不被该端点接受,所以要单独的 key。

## 用量口径

`in` 为 API 口径输入 token,含缓存命中(缓存是它的子集);今日/5h/7d 三个窗口来自 ZCode 本地数据库 `turn_usage` 表逐轮记录,纯本地统计。

## 文件

- `zcode_deck.py` 主程序 · `deck/` 服务、桥接、记账、官方额度、自启、安装器
- `启动悬浮窗.bat` 启动器 · `tests/test_roundtrip.py` 七场景回路测试(`py -3 tests/test_roundtrip.py`)
- 卸载 hook:`py -3 deck/install_hooks.py --remove`
- 错误日志在 `logs/`;协议细节与边界见 `AGENTS.md`
